# User Personas & Use Cases

`PROPOSAL` Derived from the proposal's Quadruple Helix model. To be validated with stakeholders.

## Personas

1. **Regional/municipal planner** — monitors region-level (NUTS 2) and municipal indicators; runs "what-if" scenarios; reallocates resources.
2. **Business operator** (hotel, transport, catering) — consumes anonymised forecasts via API Gateway to adjust staffing, supply, and pricing.
3. **Resident** — receives civil-protection and infrastructure alerts; reports local problems.
4. **Visitor** — receives overload/alternative-activity alerts; reports congestion and issues.
5. **Researcher** — consumes anonymised Open Data and develops further sustainability algorithms.

## Representative use cases

- UC-1: Planners view a multi-layer map correlating beach congestion, UV, and air quality.
- UC-2: A visitor receives a real-time alert redirecting them from a saturated beach.
- UC-3: A resident reports a water outage; the report is cross-verified against sensor data.
- UC-4: A business queries predicted next-week visitor load for a zone.
- UC-5: A researcher downloads anonymised 34-indicator time series via the Open Data portal.
- UC-6: A planner asks in natural language for the ecological pressure on a protected area at peak occupancy.
