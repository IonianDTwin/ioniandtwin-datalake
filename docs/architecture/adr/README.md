# Architecture Decision Records

`DECISION` Detailed, architecture-specific ADRs will be recorded here once implementation begins. Bootstrap-phase decisions (workspace isolation, local-first LLM, ~30-minute ingestion cadence) are captured in the project documentation (`ROADMAP.md`, `SECURITY_PRIVACY_ETHICS.md`).

## Format

Each ADR records:

- Status (Proposed / Accepted / Superseded)
- Context
- Decision
- Consequences
- Change log
